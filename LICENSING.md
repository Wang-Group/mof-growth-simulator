# Code and Data Licensing

The project maintainer confirmed these licenses on 2026-11-02:

- Original project software and software documentation: **MIT**, in [LICENSE](LICENSE).
- Project-produced experimental/simulation data, molecular structures, analysis tables and project-generated figures: **CC BY 4.0**, in [LICENSE-DATA.txt](LICENSE-DATA.txt).

The official texts are available from the [Open Source Initiative](https://opensource.org/license/mit)
and [Creative Commons](https://creativecommons.org/licenses/by/4.0/legalcode.en).

These grants apply only to rights held by the project contributors. Existing
third-party software licenses and copyright notices remain in force; dependencies
are not relicensed. Literature-derived entries retain their cited sources.
Third-party article text, figures, structures or other externally licensed material
are not relicensed merely by appearing in a source archive or being cited here.
Follow any file-specific terms where supplied.

For attribution, retain source credits, cite the repository and the specific release
tag/commit used, and identify changes to data. Add the paper and dataset DOI once
assigned. The curated independent-history branch does not imply that the person
creating its root commit authored every source file.

MS/SI documents are not included in this repository; their publication rights are
handled separately. This release contains no new grant over those documents.
