## 一键重画与复核

在本目录运行，使用 Python 3.11 或更新版本；推荐已有 Anaconda base 环境：

```powershell
python reproduce.py
python verify_package.py
```

依赖为 NumPy、pandas、Matplotlib；测试版本记录在 `verification_results.json`，版本文件见 `requirements.txt`。所有新图使用 Arial；其他电脑没有 Arial 时需安装字体才能获得相同排版。运行仅处理包内表格，不启动 KMC，不连接网络、不读取原始大目录、不改 MS/SI。

图表输出在 `reproduced/`，包含 PNG、可编辑 SVG 和原始算法时间统计表；验证结果显示在终端，随包附有 `verification_results.json`。原始代码与历史输出保持不变。可指定新输出目录：

```powershell
python reproduce.py --output-dir reproduced_again
```

新加的轻量重画代码集中在 `reproduce.py`。`original/` 中代码和旧 `scripts/` 是来源快照：部分依赖未打包的大 checkpoint 或模拟模块，**不是本轻量包的一键运行入口**。尤其混合 Zr6/Zr12 的旧脚本会重新模拟，不要用它代替轻量重画。

## 必须保留的科学口径

### UiO-66 时间和结构

- `01_.../data/*_s` 时间值保留历史 ×0.175 换算；本包 S7 重画用 `u = stored_scaled_time / 0.175`。这是恢复原始算法时间，不是重新确认 25 °C 的物理标定。
- `reproduced/Fig3DE_legacy_scaled/` 保留原渲染程序的秒轴以便核对历史图，**不建议直接作为统一时标后的最终稿**；另提供原始算法时间版本 `Fig3D_raw_u.png/svg`。
- 13→30 的中位配对间隔为 51.6103 u；30→1000 为 125.1358 u。配对间隔中位数不等于两个边缘中位数之差。I03 是长延迟例外，不能写成“每次首次达到 13 都立即生长”。
- 24 个最后保存的 entity-13 快照分为 9 个重建拓扑，最大组 11/24；21 个为 5 Zr6+8 BDC，3 个为 4 Zr6+9 BDC。MOL2 不含键，分类采用几何重建。不要把这组与主文 Fig. 3A 的另一个历史 20-run motif cohort 混用。

### DLS

- `data/260316.csv` 后两列已包含 90 s 准备期；不再次加 90 s。
- 40 点，117–1170 s 全范围用于拟合；已有展示图只显示 0–600 s。另输出全时段诊断图。
- 3 点居中滚动中位数；前 5 个平滑值的中位数为 baseline，末 5 个平滑值均值为 plateau；归一化并裁剪到 [0,1] 后取累计最大值作为 apparent progress。
- 模型为 `alpha(t) = [1 - exp(-(kG*t)^nG)] / [1 + exp(-(t-aN)/bN)]`。旧实现先搜索 nG∈{1,2,3}，选出 2 后再细化连续参数；不是自由连续拟合 nG，也不是事先固定 nG=2。
- 复现值：aN=215.538827 s，bN=2.512205 s，kG=0.001927994842 s⁻¹，R²=0.9726582834。R²针对处理后的 proxy；尺寸换算曲线只是可视化，不是绝对结晶度测量。

### BTB 与缺陷案例

- BTB 5000001 行原轨迹压缩为 148692 个常数段，保留每段首末时间、实体数、原始行号。它保留原绘图代码的全部 step-post 曲线；段内重复状态的中间时间戳未包含，不能代替完整事件动力学数据。
- BTB 重画横轴故意标为 `Stored Source Time`，不猜测 ms。原图 620–690 ms 的缩放和截取命令需确认；Table S27 的“减去 620 ms”与现行图轴仍需核对。
- BTB 结构频率是跨 71 个编码条件的历史统计，不是新版 direct-coordinate 扫描的无条件成核概率。分母随缺失值变化：entity 2–10 为 284，entity 1、11–13 为 283。
- 混合种子初态为 37 Zr6+37 Zr12+98 BDC=172；四次最终均 773 entities 且 Zr12=0。存储时间已乘该案例的 0.1 参数；不能再套 UiO-66 long-growth 的 ×0.175。
- 空位修复分母为原始 591 个 BDC 和 54 个 Zr 空位；N=2800 回填 132/591、54/54，N=100001 为 584/591、54/54，不是对最终所有位点的完整度。
